# KubeJS 投票スクリプト (vote.js)

Minecraftサーバー上でチャット投票を行う KubeJS 用サーバースクリプトです。
管理者が選択肢を登録して投票を開始すると、プレイヤーはチャットのクリックまたはコマンドで投票できます。制限時間が過ぎると結果が集計され、最多得票の選択肢が発表されます。

## 機能

- 選択肢の登録・一覧表示・クリア
- 制限時間(秒)つきの投票
- チャットに表示された選択肢のクリックで投票(`/vote cast` が自動実行されます)
- 投票期間中なら投票先の変更が可能(同じプレイヤーの最後の票だけが有効)
- 同票の場合は、最多得票の選択肢からランダムに1つを選出
- 全選択肢の得票数と、勝者の得票数/総投票数を表示

## 動作環境

- KubeJS 6 系(`ServerEvents.commandRegistry` が使える環境)

## 導入方法

`vote.js` を次の場所に置きます。

```
kubejs/server_scripts/vote.js
```

サーバー起動後、または `/reload` 後に有効になります。

## コマンド一覧

| コマンド | 権限 | 説明 |
|---|---|---|
| `/vote option add <label>` | OP (権限レベル2) | 選択肢を追加します |
| `/vote option clear` | OP (権限レベル2) | 選択肢をすべて削除します |
| `/vote option list` | 全員 | 登録済みの選択肢を表示します |
| `/vote start <seconds>` | OP (権限レベル2) | 指定秒数の投票を開始します |
| `/vote cast <choice>` | 全員 | 番号(1始まり)で投票します |

## 使い方

```
/vote option add "ラーメン"
/vote option add "カレー"
/vote option add "寿司"
/vote start 60
```

1. `/vote option add` で選択肢を2つ以上登録します。
2. `/vote start <秒数>` で投票を開始します。選択肢がチャットに表示されます。
3. プレイヤーは表示された選択肢をクリックするか、`/vote cast <番号>` で投票します。
4. 制限時間が来ると結果が自動で発表されます。

### 結果表示の例

```
=== 投票結果 ===
ラーメン: 3票
カレー: 3票
寿司: 1票
優勝: 「カレー」 (3/7票)
```

## 仕様・注意点

- **選択肢の数**: 投票開始には2つ以上の選択肢が必要です。
- **同時開催**: 投票中に `/vote start` を実行するとエラーになります。
- **ラベルの入力**: スペースを含むラベルは `"` で囲んでください(例: `/vote option add "カレー ライス"`)。
- **同票時の扱い**: 最多得票の選択肢が複数ある場合は、その中からランダムに1つが選ばれます。
- **無投票時**: 投票が0件の場合は、メッセージを出してキャンセルされます。
- **選択肢の保持**: 投票が終わっても選択肢は残ります。次の投票の前に、必要なら `/vote option clear` で消してください。
- **状態の保存**: 投票の状態はメモリ上にのみ保持されます。サーバーの再起動や `/reload` で選択肢・投票内容はリセットされます。投票中に `/reload` すると、集計されない場合があります。
- **コンソールからの投票**: `/vote cast` はプレイヤー実行が前提です。コンソールからは投票できません。
- **集計の識別単位**: 投票者はプレイヤー名(username)で識別されます。

## カスタマイズ

- 必要な権限レベルは、各コマンドの `.requires(src => src.hasPermission(2))` で変更できます。
- 表示メッセージは、スクリプト内の `Text.of(...)` を編集すると変更できます。
